# Data Sources

The color and logo data for this project were collected from the following reliable sports branding and media resources:

## 🎨 Team Color Palettes
- **Team Color Codes**: [teamcolorcodes.com](https://teamcolorcodes.com/) - The primary reference for HEX, RGB, and Pantone values.
- **TruColor**: [trucolor.net](https://trucolor.net/) - Historic and current league identity tracking.
- **NBA/NFL/MLB Official Brand Guidelines**: Referenced via team-specific digital style guides.
- **EPL Club Kits**: Sourced from official club shop listings for the 2024/25 season.

## 🖼️ Team Logos
- **ESPN CDN**: `https://a.espncdn.com/i/teamlogos/` - High-quality, transparent PNG assets used for consistency across all leagues.
- **SportsLogos.net**: Used for verifying historical and current logo iterations.

## 🛠️ Tools
- Data was compiled and formatted using **Gemini CLI** and validated against official league rosters for the 2024 season.
